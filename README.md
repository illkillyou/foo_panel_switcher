Panel Switcher for foobar2000





I created this so I could switch between 2 different panels without having ugly tabs or removing the element and replacing it.



\- Hosts two Default UI elements in one panel

\- Instantly toggles between the two elements

\- Remembers both configured elements

\- Remembers which element is currently active

\- Provides a main menu command for switching



Usage



After adding Panel Switcher to your layout, use Layout Editing Mode to configure the UI elements contained inside it.



To switch between the two panels, use:



View/Panel Switcher/Toggle Panel



Requirements



\- foobar2000 v2.x

\- Windows

\- 64-bit foobar2000

\- Default UI
